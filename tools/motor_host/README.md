# AT_foc_hall 简易上位机

用于代替手工输入常用串口命令。界面包含运行控制、自动辨识、参数管理、故障诊断及原始串口终端。

当前固件默认电机为 `60BLDC140-24030-14J30`（24 V），4 对极、Rs=80 mΩ、Ld=Lq=50 µH，电流 PI Q15 为 `9141/9141/914`，速度上限 3000 rpm。

## 环境

- Python 3.10 或更高版本
- PySide6
- pyserial 3.5

安装依赖并启动：

```powershell
cd tools\motor_host
python -m pip install -r requirements.txt
python motor_host.py
```

工程机也可直接复用已有环境：

```powershell
E:\src\foc_tuner\tools\python3\python.exe motor_host.py
```

串口固定使用固件当前配置：`921600, 8N1, 无流控`。

## logid 曲线调试

在“调试曲线”页选择分组、输出频率和电流 PI 细节，点击“开始”。上位机逐条等待配置应答；失败或超时会取消后续命令。“停止”仅停止曲线输出，停止电机仍使用顶部“停止电机”。可勾选曲线、按单位分图查看，并导出最近 100000 点原始 CSV；窗口绘图保留最近 2000 点。

曲线页隐藏串口日志窗口和原始命令栏，将空间全部留给绘图；切换到其他页签后恢复显示，后台接收日志不受影响。未连接或尚未收到数据时，也会按所选分组显示通道、XY 坐标和主/次网格，空图默认范围为 0～1；数据到达后按实际范围自动调整。

电流环总览（10组、总览）使用一个绘图区：Id/Iq 给定与反馈对应左侧 A 轴，Ud/Uq 对应右侧 V 轴，共享时间轴；两种单位各自自动定标。靠近左/右 Y 轴滚轮只调整对应刻度；图内缩放、框选和平移同步调整两侧刻度，锁定Y同时锁定两侧。

所有分组（包括10组D/Q细节、20速度环、30占空比/电流、40 CVP）均为单个绘图区，全部通道叠加显示。每种单位有独立数值轴：首种单位在左侧，其余单位排列在右侧，共享时间轴。靠近右侧不同的刻度区域滚轮，可分别调整该单位的范围。显示方式参考 `E:\src\foc_tuner\gui\waveform_widget.py` 的单图多通道布局。

各通道使用固定且互不重复的颜色，通道勾选文字与曲线同色；重新绘图或切换分组后回到该组，通道颜色保持一致。

曲线支持手动 X/Y 缩放和平移：

- 鼠标靠近底部 X 轴（含刻度/标题区域）滚轮只缩放时间轴，靠近左/右 Y 轴只缩放对应数值轴，无需选择缩放轴。绘图区内远离轴线时滚轮缩放 XY，以指针位置为中心；左键拖框放大。
- 中键拖动，或 Shift+左键拖动，平移视野。
- 所有分图的 X 时间轴联动，Y 轴只调整当前分图；单独调整某个 Y 轴后，该轴保持手动范围，其他轴继续自动调整。
- “锁定X/锁定Y”冻结对应轴范围，同时禁止该轴的自动调整和鼠标操作。
- 手动调整过的轴保持视野，后续数据不会覆盖其范围。双击任一绘图区，或点击“恢复自动范围”，解除轴锁定并恢复所有分图自动范围。清空数据或切换收到的数据分组时也恢复自动范围。

缩放不会停止采集；绘图仍保留最近 2000 点，较早的数据可能随持续采集移出缓存。观察某段固定波形时，可先停止曲线输出，再缩放查看。

| logid | 内容 | 默认实时输出 |
|---|---|---:|
| 10 | Id/Iq 给定与反馈、Ud/Uq；可选 D/Q 轴误差、P/I、限幅前 P+I、轴限幅后与矢量限幅后电压 | 500 Hz |
| 20 | 目标/斜坡/反馈转速、逻辑 Iq 指令与反馈、P/I、PI 限幅后输出及当前限流 | 200 Hz |
| 30 | 三相占空比、Ia/Ib/重构 Ic、母线电压 | 500 Hz |
| 40 | C=逻辑 Iq、V=逻辑机械转速、P=Hall 相对机械位置，附 Iq 指令与速度参考 | 200 Hz |

```text
logid 10
logdetail 2
lograte 500
debug 1
debug 0
logcapture 128
logid
```

`logdetail 0/1/2` 分别为电流环总览/D轴/Q轴，仅用于 10 组。`lograte` 支持 1..500 Hz，按 16 kHz 周期分频，非整除频率的周期在相邻采样周期之间交替。更改分组、细节或频率会停止当前输出并清空待发数据，需再执行 `debug 1`。配置只在 RAM 中生效，重启默认选择 20 组、200 Hz、关闭输出，不写 Flash。

`logcapture [1..128]` 仅用于 10 组，默认 128 点。它立即停止实时流，按电流控制周期采集，最多约 8 ms，采完后上传并保持实时流关闭；`debug 0` 可取消。抓取前应先启动所需的电流/速度控制，静止未启动时会记录无效电流环状态，不会自动驱动电机。当前没有阶跃或故障触发条件。

采样在 ADC 控制周期结束处执行，中断中不打印；8 帧队列交给主循环格式化，通过 USART1 TX DMA 发送。发送忙时保留队首，队列满则丢弃新实时样本并累计丢帧，控制流程不等待串口。文字应答先等待当前 DMA 帧完成，保证文字和曲线不在一行内交错。921600 波特率可能限制高字段数下的实际吞吐，以采样时间戳和丢帧数为准，不把串口到达时间当作采样时间。

30 组占空比是本次控制周期写入的比较预装载值，下一 PWM 更新点生效；相电流是本次 ADC 采样值，不能把两者误认为已同时施加/测得。PWM 关闭时比较值仍可能非零，应同时查看 PWM 标志。母线电压是最近一次慢速采样值。电流 PI 的 I 项在外部矢量限压回算前记录；P+I 为此时的限幅前请求，不能直接将限幅后的电压与 P+I 等同。

40 组位置以选择该组后的首次 Hall 样本为零点，按合法正/反边沿累计，分辨率为 `60°/极对数`（当前 15°机械角），未做扇区内位置插值。它不依赖开启日志期间的转速积分，不是编码器绝对位置，也不构成位置环。Hall 非法跳变、健康故障、计数重置、极对数变化或位置超出 int32 毫度范围时，位置有效标志失效；修复后重新选择 40 组建立零点。

### 曲线串口协议

每行固定格式为 `@T,id,detail,seq,us,drops,flags,capture,v0,...,v9`，CRLF 结束，共 18 列。整数时间戳 `us` 和序号为 uint32，时间戳约 71.6 分钟回绕；上位机处理回绕。`capture=1` 为高速抓取数据。`logid` 查询会回显当前配置和 `TRACE fields=...` 字段说明；10 组电流为物理方向，20/40 组 Iq 和速度采用逻辑方向。速度原始单位为 milli-rpm、电流 mA、电压 mV、占空比 0.01%、位置毫度，CSV 导出附带字段名和显示换算比例。v9 为对应采样/控制更新计数，不绘图。

| flags 位值 | 含义 |
|---:|---|
| 1 | 电流环运行 |
| 2 | 电流环矢量限压 |
| 4 | 软件 PWM 输出使能 |
| 8 | 三相电流采样有效（30组） |
| 16 | 母线采样有效（30组） |
| 32 | 速度反馈有效（20/40组） |
| 64 | 速度 PI 达到电流限幅（20/40组） |
| 128 | Hall 相对位置有效（40组） |
| 256 | 电流环更新计数较上一调试样本前进 |

上位机显示固件丢帧、序号缺口和解析错误。无效反馈不作为零值绘图，只绘制最近连续有效段。`debug 1` 已从旧三列纯速度 CSV 改为上述带标识协议，旧脚本需适配。

软件验证：`tests/run_motor_trace.ps1` 检查分频、队列背压/溢出、抓取长度、CVP 方向与有效性；`tests/motor_trace_host_test.py` 检查串口分包、时间戳回绕、命令应答、曲线和 CSV。仍需上板核对 UART DMA、开启日志后的中断耗时、停止响应以及采样时序。

## 使用说明

1. 选择调试串口并连接。
2. 通过页签按钮发送常用指令；底部输入框可发送任意原始CLI命令，使用上下方向键浏览已发送的历史命令。
3. 顶部“复位设备”仅发送安全复位命令；固件会拒绝电机运行或PWM开启时复位。
4. “打开调试/关闭调试”使用同一个按钮切换。
5. 开环、电流环和速度环各使用一个“启动/更新”按钮：首次点击启动，后续点击更新；停止电机或断开连接后恢复为启动状态。
6. 单项辨识启动后，软件会暂时禁用其他辨识操作，收到成功或失败回显后自动解锁。
7. 辨识成功后依次查看“参数差异”，再执行“接受候选”和“保存参数”。
8. 电机运行中不要断开串口代替停机；应先点击“停止电机”。

磁链辨识使用“自动辨识”页的“辨识磁链”按钮（`identify flux`），应先确认Rs、Ld/Lq与Hall标定参数。成功后查看参数差异，再接受候选并保存；也可在参数页手动设置 `flux_linkage_uwb`。

参数设置区域的参数名下拉框与固件当前支持的 `motor param set` 字段保持一致。

新增调试参数支持“设置候选参数 → 参数差异 → 接受候选 → 保存参数”。接受要求READY且PWM关闭，接受后RAM生效；保存后下次上电加载。Flash为v7，兼容v2～v6：原字段保留，新字段补固件默认值。修改CAN ID后对端应立即改用新ID。已失效的堵转参数从上位机列表隐藏，固件字段保留兼容。

正常Hall启动用不到的对齐电流、对齐时间、I/F最大电流和频率爬升率已从上位机参数列表隐藏；下位机和Flash字段保留兼容，启动超时仍可设置。

| 参数 | 单位 | 默认值 | 可设范围 |
|---|---|---:|---:|
| `startup_timeout_ms` | ms | 3000 | 500..15000，且大于对齐时间 |
| `offset_iq_ma` / `flux_iq_ma` | mA | 10000 | 1..20000 |
| `offset_voltage_pct` / `flux_voltage_pct` | %母线电压 | 30 | 1..57 |
| `offset_voltage_mv` / `flux_voltage_mv` | mV | 8400 | 100..27700 |
| `offset_settle_ms` / `flux_settle_ms` | ms | 2000 | 100..10000 |
| `offset_measure_ms` / `flux_measure_ms` | ms | 4000 | 100..10000 |
| `hall_scan_mv` | mV | 1200 | 100..4800 |
| `hall_scan_mhz` | 电频率mHz | 5000 | 1000..20000 |
| `speed_deceleration_rpm_per_s` | rpm/s | 30000 | 1..1000000 |
| `speed_startup_iq_slew_ma_s` | mA/s | 200000 | 1000..1000000 |
| `stall_speed_rpm`（保留字段，不生效） | rpm | 30 | 1..500 |
| `stall_time_ms`（保留字段，不生效） | ms | 1000 | 100..10000 |
| `can_node_id` | 标准帧ID，十进制 | 1 | 1..127 |

`offset_*`只影响Hall补偿，`flux_*`只影响磁链辨识；辨识会临时使用候选参数，结束后恢复原活动值，再由用户接受和保存。两种电压限制取较小值。对齐和I/F启动电流还必须低于固件的辨识中止阈值（当前25000 mA）。对齐参数属于电流启动路径，不改变速度模式的直接启动。固定等待时间不等于已通过稳速检查，Hall开环扫描仍不具备专用闭环限流。硬件保护阈值仍由固件约束。

本工具只封装现有文本协议，不绕过固件中的状态检查与安全保护。

## 打包exe（命令）

Hall实现：TMR4以1 MHz自由计数，C1锁存Hall XOR触发时标并由溢出中断扩展计数；
测速使用捕获时间，DWT仅保留事件诊断/短时超时用途。首个方向边沿不测速，
后续同向间隔逐步进入最多6段窗口；换向及长停后清旧窗口，不混入停机间隔。
正反角度表由同一套六边界标定生成。电频率至少10 Hz、同向连续有效且边界误差
不超过约15°时渐进校正，每16 kHz周期最多约1°且不超过正常角步长的一半，
避免校正使运动角度瞬间反向；低速、换向或大误差直接对齐。
实际Hall原始状态必须合法且与解码状态一致，持续不一致走约10 ms Hall失效确认；
20 ms内累计6次非法跳变锁存Hall健康故障。清故障要求原始Hall合法，并重新建立解码基线。
硬件计数扩展要求溢出中断及时服务（1 MHz、16位约65.536 ms一次），
尚需上板核对捕获触发、滤波延迟和实际角度电流波形。

控制恢复行为：提高运行限流（包括非零限流恢复）会重新启用Iq上升平滑，降低限流立即生效。
速度启动先进入状态7（SPEED_PREPARING），主循环依次推进唤醒、输入确认、预充和新采样确认，
准备期间可更新目标或停机；请求成功不等于已经进入速度闭环。
只有合法Hall连续1秒无边沿确认静止时才预充：先在MOE关闭下写零比较值并等待锁存，
再低边预充约1 ms，关闭输出后等待新电流采样。滑行跳过低边预充；
运动状态未知时等待确认，唤醒/判断阶段超时1.5秒，后续各阶段超时100 ms均故障关断。
限流或启动Iq斜率限制生效且测速落后目标至少30 rpm时，暂停继续加速参考值；
反馈追上后恢复推进，减速和换向不受此暂停逻辑阻挡。零限流期间不推进加速目标。
故障清除先在PWM关闭状态唤醒DRV并等待新电流采样，检查成功后才回READY，不自动重启。
Hall扇区角有效与运动测速有效独立；无测速时必须额外确认合法Hall静止，不能把未知速度直接当作停稳。
同向滑行启动用配置磁链和Hall电频率估算反电势作为q轴电压初值，并限制在母线允许范围；
这不是端电压实测匹配，磁链未标定时接管效果仍需验证。反向滑行先减速到零，再经确认反向加速。
